## 摘要
摄像机条件世界模型生成交互式视频，其中命令的动作应引发预期的场景变化，同时外观、几何形状和时间动态保持一致。现有的奖励方法分别评估这些需求：基于几何的奖励估计轨迹执行情况，但无法判断所执行运动的视觉质量；而基于图像的奖励衡量帧质量，却不捕捉动作执行或时间动态。我们认为，视觉-语言模型（VLM）为关联动作与其视觉结果提供了共享的推理空间。然而，用完整的动作序列评判一个完整的长视频会形成冗长、嘈杂的上下文，其中短暂出现的局部动作证据可能会被遗漏或稀释。我们提出了WorldReward，一种基于VLM的成对偏好奖励模型，统一了摄像机条件世界模型的动作一致性和视觉质量评估。WorldReward将配对的视频分解为动作对齐的片段，将每个片段组织为结构化的视觉证据，并通过投票将片段级决策聚合为独立的视频级动作偏好和视觉质量偏好。为了训练该模型，我们构建了一个大规模、推理增强的偏好数据集，该数据集使用前沿VLM生成的结构化判断，并通过基于工具的智能体审计和针对性的人工审查进行精炼。我们进一步介绍了WorldReward-Bench，这是一个人工标注的基准，用于衡量奖励模型在动作一致性、外观质量和运动质量方面与人类偏好的一致性。WorldReward在所有三个维度上取得了最高的一致性，分别超过GPT-5.5 3.42、1.45和3.56个百分点。当用于HY-WorldPlay 1.5的RL后训练时，它在短期到长期范围内持续改善了动作执行和视觉质量。

## Abstract
Camera-conditioned world models generate interactive videos in which commanded actions should induce the expected scene changes while appearance, geometry, and temporal dynamics remain coherent. Existing rewards assess these requirements separately: geometry-based rewards estimate trajectory execution but cannot judge the visual quality of the executed motion, whereas image-based rewards measure frame quality without capturing action execution or temporal dynamics. We posit that a vision-language model (VLM) offers a shared reasoning space for relating actions to their visual outcomes. However, judging a complete long video against its full action sequence creates a lengthy, noisy context in which short-lived local action evidence can be missed or diluted. We present WorldReward, a VLM-based pairwise preference reward model that unifies action-consistency and visual-quality evaluation for camera-conditioned world models. WorldReward decomposes paired videos into action-aligned chunks, organizes each chunk into structured visual evidence, and aggregates chunk-level decisions by voting into separate video-level action and visual-quality preferences. To train it, we construct a large-scale reasoning-augmented preference dataset using structured judgments generated by a frontier VLM and refined through tool-based agent auditing and targeted human review. We further introduce WorldReward-Bench, a human-annotated benchmark measuring reward-model agreement with human preferences across action consistency, appearance quality, and motion quality. WorldReward achieves the highest agreement on all three dimensions, exceeding GPT-5.5 by 3.42, 1.45, and 3.56 percentage points, respectively. When used for RL post-training of HY-WorldPlay 1.5, it consistently improves both action execution and visual quality across short- to long-term horizons.

## 2. 论文提出的方法论

### 2.1 总体框架要点

- **局部到全局（local-to-global）推断结构**：
  1. 将视频对在时间轴上对齐并切分为多个“动作块”（每个块含 4 个连续动作片段，首先将一个起辅助作用的 source-frame 空闲位前置构成一个动作槽序列，按四个动作槽一次分组）；
  2. 对每个 chunk 构造紧凑的结构化视觉输入，并让 VLM 在块内做出“动作赢家”和“视觉赢家”判断；
  3. 将各块在动作与视觉两条维度的赢家结论进行硬投票，得出整段视频的两个全局偏好结果（A / B / Tie）。

### 2.2 关键流程与输入设计

对于第 k 块，输入形式被定义为：

\(z_k=(d,\ a_{s_k:e_k},\ \mathcal{I}_k)\)，其中：
- \(d\)：图像文本描述；
- \(a_{s_k:e_k}\)：局部的连续动作段；
- \(\mathcal{I}_k\)：该块的结构化视觉证据。

**视觉证据由三部分构成**：
1. **源图像** \(x_0\)：作为场景 / 身份 / 背景参照基准，用于检测源场景漂移与外观不连续；
2. **帧网格总览（Frame-Grid Overview）**：在块内每个动作的开始、中间、结尾各抽样合成缩略网格，便于模型整体检查时间过程、物体连贯性与生成动态强度；
3. **动作级对比面板（Action-Level Panels）**：每个动作将视频 A、B 的首帧与尾帧并列显示，降低局部转场比对难度。

文本描述与这些视觉信息作为共同上下文传入 VLM。

### 2.3 Chunk 级奖励推理

VLM 在单一推理过程中同时产出两类判断：
- **动作一致性**：模型在块内逐一比较视频 A/B 的各动作，判断所对应的场景转变是否匹配“平移/旋转/复合”指令。每一项动作先判断 winner ∈ {A, B, Tie}，再综合出该块的动作偏好。
- **视觉质量偏好**：细化为三个子维度：
  - 时间一致性（帧差异、闪烁、材质稳定度）；
  - 动态生成质量（是否给出合理的摄像机 3D 动态、视差、运动体积感而非 2D pan and zoom）；
  - 伪影/结构完整性（生成伪影、结构退化、原场景信息保持）。
  若两个视觉子维度在该块内喜欢不同候选视频，则块级外观预测标为 Tie；
  运动质量则直接依据动态生成质量结果；经过上述操作后，得到视觉方面的两个视频级偏好。

### 2.4 视频级投票聚合

- 令第 k 块的奖项为 \(r_k^{act}, r_k^{vis}\)，对两个模型在 nA、nB 计数做全局比较：
  - 若 A 获胜次数大于 B 则全局选 A、反之选 B；若二者相等则全局为 Tie。
- 各块内 Tie 不偏向任一方；每个块都可以被独立判断，从而减少某一局部强段影响整体结论的干扰。

### 2.5 训练数据集构建（推理增强偏好数据管件）

本文构建了一个规模较大的三阶段数据生产管线：
1. **输入多样性设定**：
   - 数据按 内容（生活空间、城市公共、交通运输、自然风景、灾害等）和 风格（照片、3D 游戏、动漫、艺术类）以及 动作轨迹族（纯平移 / 纯旋转 / 复合动作）细分。
2. **成对视频生成**：
   - 从 HY-WorldPlay 及其后训练变体、LingBot-World-Fast、Infinite-World、Yume-1.5、SANA-WM、Matrix-Game 等八种模型变体中随机配对；
   - 对同一 source image、caption 与 action trajectory 进行受控生成，而且分配集中在各模型所支持的控制空间内；
   - 由此产出 50,000 个视频对，每个 11 步轨迹 + 初始空闲位 → 拆 3 chunk → 得出约 150,000 个 chunk，亚采样成约 100,000 个训练样本。
3. **知识蒸馏与注释修订**：
   - 先让 Gemini 3.1 Pro 按上述 protocol 输出 chunk 级推理；
   - 然后用 GPT-5.5 作为“多回合智能体 QC”，通过图像读取工具自适应迭代，仅围绕被怀疑的部分进行复核与修订；
   - 修订结果交由人工校准验证；
   - 总体统计显示：原始判据保留 57.9%，42.1% 被 agent 提出修订，其人工确认命中率为 87.0%。

### 2.6 RL 后训练协议

在奖励被用于世界模型 RL 后训练时，作者沿用 WorldCompass 的 clip-drop 与 DiffusionNFT 流匹配目标，但**改造两个关键部分**：
- 把原用作“几何奖励 + 图像奖励”的异构奖励改为 WorldReward 在单一上下文输出的双维度奖励；
- 对同一 rollout 候选组使用 Pref-GRPO 式“胜率归一化奖励”；
- 最终用 \(\lambda A^{\mathrm{act}} + (1-\lambda)A^{\mathrm{vis}}\) 组合优势，配合负向感知 flow-matching 损失进行优化。

### 2.7 WorldReward-Bench 基准构建

- 由 760 个配对视频组成，来源独立于训练数据（不同图像、文本与更新的轨迹库，并包含更长 23 步轨迹和 184 帧输出）；
- 轨迹覆盖纯平移 / 纯旋转 / 复合动作，风格含照片 / 游戏与动漫 / 艺术等；共来自 8 个世界模型。
- 对每个视频对由 3 名不知晓生成来源的标注员独立评价，并使用多数投票确定最终答案；
- 三个评价维度独立：动作一致性、外观质量、运动质量，并显式允许 Tie。
